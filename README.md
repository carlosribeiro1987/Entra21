# Entra 21 2026 - Curso Java

Este repositório contém todas as atividades desenvolvidas durante o curso de Java do Entra21 de 2026.

- `Aula 01 [2026-03-31]` - exercícios iniciais com operações básicas.
- `Aula 02 [2026-04-10]` - continuação dos conceitos introdutórios.
- `Aula 05 [2026-04-13]` - média de notas e lógica básica.
- `Aula 06 [2026-04-14]` - estruturas de controle e classes.
- `Aula 07 [2026-04-17]` - manipulação de números, loops e tabuada.
- `Aula 08 [2026-04-24]` - exemplos com while, interface de texto e votações.
- `Aula 09 [2026-04-27]` - uso de arrays e percorrimento.
- `Aula 10 [2026-04-28]` - introdução a `ArrayList` e projetos de sistemas.
- `TrabalhoConclusaoModulo01` - projeto final de conclusão do primeiro módulo.
- `TrabalhoModulo01` - atividades práticas e sistema de cadastro.

## Como usar

1. Abra o diretório no seu editor ou IDE Java de preferência.
2. Compile os arquivos `.java` com o JDK instalado.
   - Exemplo:
     ```bash
     javac Aula\ 10\ [2026-04-28]\\SistemaCarros.java
     ```
3. Execute a classe principal desejada:
   - Exemplo:
     ```bash
     java SistemaCarros
     ```

> Observação: os nomes de diretórios e arquivos podem conter espaços. No Windows, use aspas ou escape os espaços no terminal.
